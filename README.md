# IndianOnion

An India-specific satirical news brand — in the spirit of The Onion / The Fauxy —
published purely through git and GitHub Actions to X and Instagram, with no
website and no human in the loop.

- **`PLAN.md`** — the full architecture: content generation, humor evaluation,
  automated safety guardrail, image generation, posting integration, secrets,
  prerequisites, risks, and verification plan.
- **`PROGRESS.md`** — dated log of what's actually been done, updated every
  session. Read this first to know where the project actually stands, since
  chat history behind this repo is ephemeral and not a reliable record.

Status: **planning complete, implementation not started.** See `PROGRESS.md`
for the current state and next steps.
